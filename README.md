# My ToDoList

タスク管理とリマインダー機能を備えたWebアプリケーションです。

日々の予定やタスクを整理し、忘れずに管理できることを目的として開発しました。

細部まで拘りました、ぜひ使ってみてください！

## アプリ

**[My ToDoListを開く](https://todolist-ckm.pages.dev)**

ブラウザからアクセスして利用できます。

※ 初回利用時はアカウント登録が必要です。

プッシュ通知を利用する場合

iPhoneでは、Safariでアプリを開き、ホーム画面に追加してください。その後、ホーム画面からアプリを起動してログインし、通知を有効にしてください。

ホーム画面に追加することで、通常のアプリに近い操作感で利用できます。


**開発の背景**

このアプリを開発したきっかけは、身近な人の生活を少しでも便利にしたいと考えたことです。

私の母は、薬の服用を始めてから物忘れが増え、薬を受け取りに行く予定を忘れてしまうことがありました。

そんな母の姿を見て、「日常生活の中で忘れてしまうことを減らし、少しでも安心して生活できるようにしたい」 と考えたことが、My ToDoListの開発につながりました。

最初に開発した旧バージョンでは、タスクの登録や管理はできるものの、通知機能がありませんでした。そのため、アプリを開いて確認しなければ予定を思い出すことができず、継続的な利用には課題がありました。

そこで、「タスクを記録するだけでなく、必要なタイミングで思い出せるアプリにしたい」 と考え、プッシュ通知機能を備えた新しいMy ToDoListを開発しました。

また、期限の早い順にタスクを自動で並び替える機能を実装し、優先して取り組むべきタスクを把握しやすくしました。

この開発では、単に機能を実装するだけでなく、実際に使う人の立場に立ち、日常生活の中にある課題を解決することを大切にしました。


## 主な機能

### 1. ユーザー認証
- メールアドレスとパスワードによる新規登録
- ログイン・ログアウト

### 2. タスク管理
- カテゴリー（タイトル）の作成・削除
- カテゴリー（タイトル）のピン留め・通知設定（期限・時刻の設定）
- タスクの追加・削除
- タスクの完了状態の管理
- タスクの期限・時刻の設定
- 期限順の自動並び替え機能

### 3. リマインダー・通知
- タスクの予定時刻にプッシュ通知を送信
- 対応端末での通知許可・端末登録
- iPhoneのホーム画面に追加したWebアプリでの通知に対応

### 4. データ保存・同期
- Cloud Firestoreを使用したデータ保存
- 同じアカウントでログインした端末間でのデータ共有

## 使用技術

| 分野 | 使用技術 |
|---|---|
| フロントエンド | HTML / CSS / JavaScript |
| ユーザー認証 | Firebase Authentication |
| データベース | Cloud Firestore |
| プッシュ通知 | Firebase Cloud Messaging |
| 通知の定期処理 | Cloudflare Workers |
| ホスティング | Cloudflare Pages |
| バージョン管理 | Git / GitHub |

## 開発で工夫した点

**直感的に操作できるUI**

タスクの追加や管理を簡単に行えるよう、画面構成やボタンの配置を考えました。

**複数端末での利用**

Firebaseを利用し、ログインしたアカウントに紐づくタスクデータを保存する仕組みを実装しました。

**プッシュ通知機能**

物忘れに悩む人が利用することを想定し、アプリを開いていない状態でも予定を思い出せるよう、プッシュ通知機能を実装しました。

Firebase Cloud MessagingとCloudflare Workersを組み合わせ、設定された通知日時に応じてリマインダーを送信する仕組みを構築しました。

 **タスクの自動並び替え**

登録されたタスクを期限の早い順に自動で並び替えることで、優先して取り組むべきタスクを一目で把握できるようにしました。

これにより、予定の見落としを減らし、効率的なタスク管理をサポートします。

**開発中に直面した課題と解決方法**

**1. プッシュ通知の不具合**

iPhoneで通知が届かず、PCでは重複して届く問題が発生しました。Firebaseの端末登録情報を確認し、テスト環境を整理して再登録することで、正常に通知を受信できることを確認しました。

**2. 端末ごとのレイアウトの違い**

PCとスマートフォンで表示が異なる問題に対し、CSSの画面幅や余白を見直し、レイアウトを調整しました。

これらの経験を通して、**問題の原因を一つずつ調査・検証し、改善することの重要性**を学びました。


**今後の改善**

今後は、実際の利用を通して使いやすさを検証し、必要な機能の追加や改善を行っていきたいと考えています。

特に、通知機能の安定性や操作性を向上させ、より安心して日常的に利用できるアプリを目指します。
